# ALKY WALLET

ALKY WALLET es una aplicación web educativa que simula funciones básicas de una cartera digital: inicio de sesión, envío de dinero, depósito y visualización de transacciones. Está pensada como proyecto práctico para aprender y demostrar uso de HTML, CSS y JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)
- Estructura de archivos estática (archivos .html y .js en el repositorio)

## Principales funcionalidades

- Inicio de sesión y control básico de acceso (`login.html`, `assets/js/login.js`).
- Envío de dinero entre cuentas simuladas (`sendmoney.html`, `assets/js/sendmoney.js`).
- Depósitos simulados (`deposit.html`).
- Visualización del historial de transacciones (`transactions.html`).
- Interfaz sencilla y validaciones de formulario en el frontend.

## Estructura del proyecto

- `index.html` — Página principal
- `login.html` — Formulario de inicio de sesión
- `sendmoney.html` — Interfaz para enviar dinero
- `deposit.html` — Interfaz para depósitos
- `transactions.html` — Listado de transacciones
- `assets/css/` — Estilos
- `assets/js/login.js` — Lógica de inicio de sesión
- `assets/js/sendmoney.js` — Lógica de envío de dinero

## Cómo usar

1. Abrir `index.html` en un navegador modern o desplegar el contenido en un servidor estático.
2. Usar `login.html` para acceder (si el proyecto implementa validaciones locales).
3. Probar el envío de dinero desde `sendmoney.html` y revisar `transactions.html`.
